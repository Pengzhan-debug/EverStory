## 1. 项目定位

EverStory 是一个“LLM 提案、规则引擎裁决”的多智能体协作调查游戏。玩家担任首席调查员，与案件主管、现场调查员、案件分析师和质疑者在联合调查室中讨论、互相质疑、提出任务并批准行动。

项目解决大模型长程交互中的事实遗忘、状态矛盾、越权修改和证据幻觉问题：LLM 负责理解玩家意图、生成角色对话和提出调查建议；人物位置、物品所有权、时间、任务、证据与结局由确定性状态机保存和校验。只有通过规则验证的结构化动作才能改变世界。

主要技术栈：

- Python、FastAPI、SQLAlchemy、Alembic；
- PostgreSQL 持久化用户、调查进度、存档、模型配置和调用记录；
- Redis/Valkey 负责跨进程会话协调、配额及熔断；
- OpenAI-compatible API、按智能体路由、平台 API 与玩家 BYOK；
- SSE 流式回复；
- 原生 HTML、CSS、JavaScript 响应式前端；
- Docker、Render Blueprint、GitHub Actions；
- 中英文切换、Token/费用/延迟可视化。

## 2. 已有产品能力

- “失落灯塔”主案件可游玩，玩家从风暴海岸开始，不应直接出生在守塔人木屋。
- 玩家可在主界面用自然语言行动，同时看见自己的发言和角色/叙事者回复。

- API 控制台在新标签页打开；返回游戏时优先聚焦原标签页，不重新初始化游戏。
